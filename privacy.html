Privacy Policy

Terakhir diperbarui: 7 November 2026

Privacy Policy ini menjelaskan bagaimana Discord Template Bot (“Bot”) memproses informasi ketika digunakan di server Discord. Pengelola Bot adalah [NAMA PENGELOLA] dan dapat dihubungi melalui [EMAIL KONTAK].

1. Informasi yang diproses

Berdasarkan fungsi dan implementasi Bot saat ini, informasi berikut dapat diproses:

  • Server/Guild ID: digunakan untuk mengelompokkan dan menemukan template khusus milik masing-masing server.
  • Data template khusus: nama template, deskripsi, nama kategori, nama channel, jenis channel, serta pilihan permission yang dimasukkan administrator. Data ini disimpan sebagai file JSON pada penyimpanan lokal lingkungan tempat Bot dijalankan.
  • User ID Discord: diproses sementara ketika administrator membuat draft role, agar hanya pengguna yang memulai proses tersebut yang dapat melanjutkannya. Draft berada di memori dan kedaluwarsa setelah sekitar 10 menit atau ketika Bot dimulai ulang.
  • Username/tag Discord: dapat dicantumkan dalam alasan audit ketika Bot membuat role, sehingga informasi tersebut dapat tercatat pada audit log server Discord.
  • Informasi server, channel, dan role: Bot mengakses informasi yang diperlukan melalui Discord API untuk memeriksa permission, membuat struktur channel, menghapus channel saat fitur Replace dikonfirmasi, dan membuat role.
  • Informasi teknis dan error: pesan error tertentu dapat ditulis ke console/log proses Bot untuk membantu pemecahan masalah. Isi dan masa penyimpanan log bergantung pada konfigurasi penyedia hosting yang digunakan pengelola.

2. Informasi yang tidak diminta oleh Bot

Implementasi Bot saat ini hanya menggunakan Gateway Intent Guilds. Bot tidak meminta akses untuk membaca isi pesan server, riwayat pesan, atau daftar anggota melalui privileged message/member intents. Jangan mengirim data pribadi atau rahasia ke dalam nama maupun deskripsi template karena data tersebut dapat tersimpan sebagai bagian dari template khusus.

3. Tujuan penggunaan informasi

  • Menyediakan dan menjalankan perintah Bot.
  • Menyimpan, menampilkan, dan menghapus template khusus berdasarkan server.
  • Memastikan tindakan administratif hanya dilakukan oleh pengguna yang memiliki permission yang sesuai.
  • Membuat channel, kategori, dan role sesuai pilihan administrator.
  • Mendiagnosis kesalahan dan menjaga keamanan serta kestabilan Bot.

4. Penyimpanan dan masa retensi

Template khusus disimpan dalam file JSON pada direktori data Bot, dipisahkan berdasarkan Server/Guild ID. Template tetap tersimpan sampai dihapus menggunakan perintah /template-delete atau dihapus secara manual dari penyimpanan tempat Bot dijalankan. Menghapus Bot dari server Discord tidak otomatis menghapus file template dari hosting Bot.

Draft pembuatan role hanya disimpan sementara di memori selama maksimal sekitar 10 menit dan hilang ketika Bot dimulai ulang. Log teknis dapat disimpan oleh lingkungan hosting sesuai pengaturan retensi penyedia tersebut.

5. Pembagian informasi

Pengelola tidak menjual informasi pengguna. Informasi diproses melalui Discord API agar Bot dapat berfungsi. Informasi juga dapat diproses oleh penyedia hosting yang digunakan untuk menjalankan Bot, sesuai layanan dan kebijakan penyedia tersebut. Discord dan penyedia hosting memiliki kebijakan privasi masing-masing.

Informasi dapat diungkapkan apabila diwajibkan oleh hukum atau diperlukan untuk menangani penyalahgunaan, keamanan, maupun perlindungan hak yang sah.

6. Keamanan

Pengelola menerapkan langkah yang wajar sesuai kemampuan dan lingkungan hosting untuk melindungi data Bot. Namun, tidak ada sistem penyimpanan atau transmisi yang dapat dijamin sepenuhnya aman. Pemilik server sebaiknya membatasi permission Bot dan akses ke mesin/hosting tempat Bot berjalan.

7. Hak dan pilihan administrator server

  • Administrator dapat menghapus template khusus dengan perintah /template-delete.
  • Administrator/pengelola Bot yang memiliki akses ke hosting dapat menghapus file template terkait secara manual.
  • Administrator dapat menghapus Bot dari server untuk menghentikan pemrosesan baru di server tersebut. Penghapusan Bot tidak dengan sendirinya menghapus data yang sudah tersimpan di hosting.
  • Untuk pertanyaan atau permintaan terkait data, hubungi pengelola melalui kontak di bawah.

8. Privasi anak

Bot merupakan alat administrasi server dan tidak dirancang khusus untuk mengumpulkan informasi pribadi anak. Pengelola server bertanggung jawab memastikan penggunaan Discord dan Bot sesuai batas usia serta ketentuan hukum yang berlaku di wilayah masing-masing.

9. Perubahan Privacy Policy

Kebijakan ini dapat diperbarui apabila fitur, cara pemrosesan data, atau persyaratan hukum berubah. Versi terbaru dan tanggal pembaruan akan tersedia pada halaman ini.
